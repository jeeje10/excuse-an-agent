An entry for make.fun's "The One-Line Excuse an Agent Gives Its Human" bounty: one line, at most 160 characters — the excuse an AI agent gives its human for missing a deadline. main.ts writes the line to /output/entry.txt.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
